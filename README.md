# Pomodoro App

## Project Name
Pomodoro Timer Application

## Project Description
A React-based Pomodoro Timer application that helps users manage their time using work sessions and short breaks.

## Features
- 25-minute Pomodoro timer
- Short break timer
- Start timer
- Stop timer
- End timer
- Simple user interface

## Technologies Used
- React.js
- JavaScript
- HTML
- CSS
- Jest Testing

## Installation

1. Clone the repository.
2. Run `npm install`.
3. Run `npm start` to launch the application.
4. Run `npm test -- --watchAll=false` to execute tests.
